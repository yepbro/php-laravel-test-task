# MarketHub: вебхуки для продавцов

MarketHub отправляет продавцу события об изменениях его заказов. Адрес для вебхуков и секрет подписи
продавец получает в личном кабинете.

## Запрос

- Метод `POST`, тело — JSON в кодировке UTF-8, `Content-Type: application/json`.
- Заголовки:

  | Заголовок | Значение |
  |---|---|
  | `X-Webhook-Id` | идентификатор события, совпадает с полем `id` в теле |
  | `X-Webhook-Timestamp` | время отправки запроса, Unix time в секундах |
  | `X-Webhook-Signature` | подпись запроса в формате `sha256=<hex>` |

## Подпись

Подпись — HMAC-SHA256 от строки `{X-Webhook-Timestamp}.{тело запроса}` с секретом продавца,
результат в нижнем регистре в hex. Тело используется ровно в том виде, в каком пришло в запросе,
байт в байт.

Рекомендуем отклонять запросы, у которых `X-Webhook-Timestamp` отличается от текущего времени больше
чем на 5 минут.

Пример расчёта — [`examples/signature-example.md`](examples/signature-example.md).

## Доставка и повторы

- Доставка считается успешной, если продавец ответил кодом `2xx` не позже чем через 5 секунд.
  Тело ответа MarketHub не анализирует.
- При любом другом ответе или таймауте MarketHub повторяет доставку: до 8 повторных попыток
  в течение примерно двух суток, с увеличивающимся интервалом. После последней неудачной попытки
  событие больше не отправляется.
- При повторе событие приходит с тем же `id`, но с новым `X-Webhook-Timestamp` и новой подписью.
- В редких случаях событие может быть доставлено повторно и после успешного ответа.
- Порядок доставки событий не гарантируется.

## Событие

```json
{
  "id": "evt_01JAXM4Q9T6V2K8R3N5W7Y0ZBC",
  "type": "order.paid",
  "created_at": "2026-10-21T10:05:48+00:00",
  "data": {
    "order": { "...": "полный снимок заказа, см. ниже" }
  }
}
```

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | уникальный идентификатор события |
| `type` | string | тип события |
| `created_at` | datetime | время создания события |
| `data.order` | object | полный снимок заказа на момент события |

### Типы событий

| Тип | Когда приходит |
|---|---|
| `order.created` | заказ оформлен |
| `order.updated` | изменились данные заказа (состав, адрес, суммы) без смены статуса |
| `order.paid` | заказ оплачен |
| `order.shipped` | заказ передан в службу доставки |
| `order.delivered` | покупатель получил заказ |
| `order.cancelled` | заказ отменён |

Список типов может расширяться без предварительного уведомления.

## Заказ

| Поле | Тип | Описание |
|---|---|---|
| `id` | string | идентификатор заказа в MarketHub |
| `number` | string | номер заказа, который видит покупатель |
| `status` | string | статус заказа, см. ниже |
| `currency` | string | код валюты ISO 4217; сейчас используются `RUB`, `USD`, `EUR` |
| `customer.email` | string | |
| `customer.name` | string | |
| `customer.phone` | string \| null | |
| `items[].sku` | string | артикул |
| `items[].name` | string | название товара |
| `items[].quantity` | integer | количество |
| `items[].price` | amount | цена за единицу |
| `delivery_price` | amount | стоимость доставки |
| `discount` | amount | скидка на заказ |
| `total` | amount | итог к оплате: сумма позиций + доставка − скидка |
| `shipment` | object \| null | данные отправки, появляются после передачи в доставку |
| `shipment.carrier` | string | служба доставки |
| `shipment.tracking_number` | string | трек-номер |
| `shipment.tracking_url` | string | ссылка на отслеживание |
| `paid_at` | datetime \| null | время оплаты |
| `cancelled_at` | datetime \| null | время отмены |
| `cancel_reason` | string \| null | причина отмены |
| `created_at` | datetime | время оформления заказа |
| `updated_at` | datetime | время последнего изменения заказа, с точностью до секунды |

Форматы:

- **amount** — строка с двумя знаками после точки: `"1499.90"`;
- **datetime** — ISO 8601 с указанием смещения часового пояса: `"2026-10-21T14:05:09+03:00"`.

### Статусы заказа

| Статус | Значение |
|---|---|
| `created` | заказ оформлен и ожидает оплаты |
| `paid` | заказ оплачен |
| `shipped` | заказ передан в службу доставки |
| `delivered` | покупатель получил заказ |
| `cancelled` | заказ отменён |

Обычный путь заказа: `created` → `paid` → `shipped` → `delivered`. До передачи в доставку заказ может быть
отменён — как до оплаты, так и после неё.

В исключительных случаях поддержка MarketHub может вручную исправить статус заказа — например,
если доставка была отмечена по ошибке.

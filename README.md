# Тестовое задание: PHP / Laravel

Задание — в [`task/README.md`](task/README.md).

Как начать:

1. Создайте свой публичный репозиторий из этого шаблона: **Use this template** → **Create a new repository**.
2. Разместите Laravel-проект в корне репозитория. Composer не создаёт проект в непустой папке,
   поэтому создайте его во временной папке и перенесите файлы сюда. Папку `task/` не меняйте.
3. Замените этот `README.md` инструкцией по запуску вашего решения.
4. Когда закончите, пришлите нам ссылку на репозиторий.
